# Safari host app

Run `xcodegen generate` in this directory to regenerate `VenueRank Lens.xcodeproj` from `project.yml`. Open the project in a full Xcode installation, select your signing team for both targets, and run the `VenueRank Lens` scheme.

The app opens Safari's Extensions settings. Enable VenueRank Lens and grant access only to the supported publication sites.
